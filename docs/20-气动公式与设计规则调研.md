# 气动公式与设计规则调研（LLM 主导、规则辅助）

**日期：** 2026-11-02  
**定位：** 内置公式和规则是 LLM/技术输入的辅助工具，不是硬性设计规则  
**代码入口：** `ai/ai_design/aero_rules.py`、`openvsp_list_design_rules` 工具

## 1 设计权原则

新的设计流程按以下优先级工作：

1. 用户技术输入、任务约束和明确工程要求；
2. LLM 的工程判断、方案权衡和工具选择；
3. 内置气动公式/经验规则：只提供默认起点、快速估算、风险提示和适用域说明；
4. VSPAERO/VSP 工具的真实计算结果和证据。

因此：

- 不再用固定经验阈值自动否决用户方案；
- 经验准则失败时，保留用户参数并报告风险，不自动篡改；
- 没有用户明确要求的参数可以用规则默认值；
- 所有公式和规则必须标注输入、单位、适用域、来源和不确定性；
- 可靠性状态仍区分“任务完成、可行、证据充分、推荐”。

## 3 还需要补充的公式和规则

### P0：优先补齐，直接影响方案可信度

1. **部件阻力积累 CD0**
   - `CD0 = Σ(Cf·S_wet·FF·IF)/S_ref + CD_misc`
   - 需要机身、机翼、尾翼、起落架、附件湿面积、形状因子和干扰因子。
2. **真实配平与配平阻力**
   - `ΣM_CG=0`，升降舵/重心/推力联合配平；
   - 不能把未配平极曲线的 L/D 当作任务 L/D。
3. **质量/重心/惯量包线**
   - 部件质量、装载组合、前后重心极限、Ixx/Iyy/Izz；
   - 质量不确定度要进入稳定性和动力学计算。
4. **螺旋桨/电机/发动机模型**
   - `J=V/(nD)`、`T=C_T ρ n²D⁴`、`P=C_P ρ n³D⁵`、`η=J C_T/C_P`；
   - 需要螺旋桨 map 或可信的推力/功率模型，不能用常数效率覆盖全包线。
5. **任务性能**
   - 起飞/着陆滑跑、爬升率/升限、盘旋/过载、航时/航程；
   - 必须按高度更新密度、推力和功率。
6. **适用域和不确定性**
   - Re/Mach、VLM 薄面/厚体假设、线化范围、网格、未建模项；
   - 输出敏感性、容差、证据等级和 blocked 项。

### P1：提高设计质量

1. **有限翼升力线斜率与 CLmax 平面形状修正**
   - `CLα = 2πAR/(2+sqrt(AR²β²/η²+4))`（DATCOM 形式）；
   - 二维翼型 CLmax 不能直接当全机 CLmax。
2. **尾翼下洗、动压损失和失速**
   - `CL_h=CL_hα(α+i_h-ε-α_0)`、`q_h/q=η_h`；
   - T 尾深失速、平尾失速、双垂尾遮蔽要单独建模。
3. **双垂尾/多垂尾有效面积**
   - `S_v_eff=k_shadow ΣS_v_i`，间距、平尾尾流、侧滑角影响；
   - 不能把两片几何面积直接相加。
4. **操纵面效能和铰链力矩**
   - `Cl_δa`、`Cm_δe`、`Cn_δr`，舵面几何、尾臂、q、限位和铰链力矩；
   - 当前仅有粗略经验值。
5. **压缩性阻力上升**
   - 设计 Mach > 0.3 时加入 `M_crit`/波阻修正；低速无人机可标注不适用。
6. **多工况/多任务点**
   - 巡航、爬升、盘旋、失速、侧风/侧滑分别计算，不只看单一极曲线。

### P2：专项能力，不能仅靠经验规则

1. **气动弹性/颤振/发散**
   - 需要结构刚度、质量分布、气动耦合分析；VSPAERO 静气动结果不能直接给颤振结论。
2. **高升力装置**
   - 襟翼/缝翼几何、铰链、滑流影响和增升效率。
3. **螺旋桨-机翼干扰/滑流**
   - 需要螺旋桨流场与机翼干扰模型。
4. **风洞/试飞相关性**
   - 雷诺数、壁面、支架、湍流度修正和不确定度。
5. **结构/制造约束**
   - 翼梁、接头、起落架、电池安装、维修口盖；这些需要结构/工艺模型，不是气动规则。

## 4 规则库的工程约束

每条规则至少包含：

```text
id, category, level(P0/P1/P2), status(implemented/partial/needed),
name, formula, inputs, outputs, note, source
```

LLM 通过 `openvsp_list_design_rules` 查询，规则输出明确 `authority=advisory`。  
`openvsp_evaluate_design` 也标记 `authority=advisory`，只提供建议/风险，不自动修改几何。

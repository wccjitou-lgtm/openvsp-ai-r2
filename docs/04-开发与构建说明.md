## 3. 构建命令

```powershell
$src = "<OPENVSP_ROOT>\work\OpenVSP-3.51.3-src"

# 增量构建（首次会重建较大范围）
cmake --build "$src\build\vsp" --config Release --target vsp --parallel 4

# 产物
#   $src\build\vsp\src\vsp\Release\vsp.exe
```

若 CMakeLists 新增文件后未生效，重新跑一次构建即可触发 ZERO_CHECK 重新生成 vcxproj。

### 3.1 从干净源码重建（可选）

参考 R1 `tools/packaging/BUILD-WINDOWS.md`：

```powershell
$src = "<OPENVSP_ROOT>\work\OpenVSP-3.51.3-src"
cmake -S "$src\Libraries" -B "$src\build\Libraries" -G "Visual Studio 17 2022" -A x64
cmake --build "$src\build\Libraries" --config Release --parallel 4
cmake -S "$src" -B "$src\build\vsp" -G "Visual Studio 17 2022" -A x64 `
  -DVSP_LIBRARY_PATH="$src\build\Libraries" -DVSP_NO_API_WRAPPERS=ON `
  -DVSP_NO_DOC=ON -DVSP_NO_PYDOC=ON -DBUILD_TESTING=ON
cmake --build "$src\build\vsp" --config Release --parallel 4
```

## 4. R2 测试

### 4.1 UI 快速检查

1. 将新 `vsp.exe` 复制到测试应用目录（例如 R1 载荷副本）；
2. 启动，确认菜单栏出现 **AI**；
3. 设置 `OPENVSP_AI_AUTOSTART=1` 启动可自动打开 AI 面板（用于截图/CI）；
4. 在面板中点击“获取模型列表”（无 Key 时应回退内置模型清单）。

自动化截图脚本参考 `ui-tests/`（`pywin32 + PrintWindow`，需 DPI-aware Python 进程）。

### 4.2 AI 后端

```bat
cd <REPO_ROOT>\ai
python -m pytest tests -q
:: 或离线端到端
python ai_design_agent.py --config examples\offline_config.json --offline
```

后端 stdout 必须逐行带有 `[status]/[tool]/[plan]/[error]` 前缀，结束时写 `result.json`。

### 4.3 MCP 服务器

```bat
cd <REPO_ROOT>\mcp
python tests\test_stdio.py
```

测试覆盖 `initialize → tools/list → tools/call(openvsp_status) → tools/call(openvsp_build_aircraft)`。

## 5. R2 打包

```powershell
python <REPO_ROOT>\scripts\package_r2.py
```

打包脚本：

1. 复制 R1 安装载荷到 `dist/OpenVSP-3.51.3-zh-CN-r2/`；
2. 覆盖为 R2 新 `vsp.exe`；
3. 加入 `ai/`（AI 后端 + 模板 + 示例 + 测试）、`mcp/`（MCP 服务器）、`docs/`（R2 文档）、`patches/`（源码修改）；
4. 生成 `README-R2-zh-CN.txt`、`VERSION-R2.txt`、`setup_ai_env.bat`，更新 `MODIFICATIONS.txt`；
5. 打包 `OpenVSP-3.51.3-zh-CN-r2-Portable.zip` 并输出 SHA-256。

## 6. 后续开发建议

1. **嵌入式 Python**：将 Python 3.13 embeddable + numpy/python-docx/openvsp 打入 `ai\python`，实现“开箱即用”；
2. **MCP modern 协议**：增加 2026-07-28 dual-era（`_meta` 版本、`server/discover`）；
3. **GUI 嵌入式助手**：将对话区改为 FLTK 原生聊天面板，支持流式 token、工具卡片、成本统计；
4. **VSPAERO 稳定性**：对厚体+薄面+操纵面切口建立自动降级/网格检查；或引入 CFD 接口；
5. **报告模板化**：支持用户自定义模板目录、图表插入（VSPAERO 极曲线/稳定性图）；
6. **安装器**：复用 R1 `tools/packaging/build_windows.py` + NSIS，生成 R2 Setup.exe（需处理 Python 依赖与 `ai/` 载荷）。

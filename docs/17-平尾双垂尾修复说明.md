# 平尾 + 双垂尾未执行的原因与修复

**日期：** 2026-11-02  
**问题：** 输入“尾翼为平尾+双垂尾”后，生成的仍然是常规单垂尾。

## 1 原因

不是 OpenVSP 无法建双垂尾，而是 R2 的规则解析和几何生成没有覆盖这个组合：

1. 配置关键词表只识别“常规尾 / 常规布局 / 水平尾翼 / t 尾”，没有单独的“平尾”；
2. `DesignSpec` 没有“垂尾数量/双垂尾”字段，默认只能生成一片垂尾；
3. `size_aircraft()` 的常规尾分支只创建 `vtail_conventional` 一个部件；
4. OpenVSP 桥接层的 `_add_vertical_fin()` 没有独立的 Y 偏移输入；
5. 因此“双垂尾”被静默忽略，没有报错，也没有假设日志。

## 2 修复

- 新增 `DesignSpec.twin_vtail`；
- 识别“平尾”“双垂尾”“双立尾”“两片垂尾”“twin vertical tail”等关键词；
- 常规布局生成：
  - `VTailL`，位于平尾左端；
  - `VTailR`，位于平尾右端；
  - 每片面积为目标垂尾总面积的一半；
  - 总垂尾容量 `Vv` 保持不变；
  - 增加 `RudderL`、`RudderR` 操纵面；
- 桥接层 `_add_vertical_fin()` 增加 `y_offset_m`，修正左右垂尾 Y 位置；
- 报告显示“双垂尾”、总垂尾面积、单片垂尾面积；
- 新增回归测试和实际 VSPAERO E2E。

## 3 验证

测试输入：

> 设计一架常规布局无人机，最大起飞重量50 kg，任务海拔1000 m，巡航速度25 m/s，低速失速速度不超过22 m/s，任务载荷5 kg，翼展不超过3.6 m；尾翼为平尾+双垂尾，采用电动机。

结果：

- 部件数：5（机身、主翼、平尾、左垂尾、右垂尾）；
- `VTailL`：Y = -0.478 m；
- `VTailR`：Y = +0.478 m；
- 控制面：`RudderL`、`RudderR`；
- 总垂尾面积：1.5325 m²，单片 0.76625 m²；
- 总垂尾容量系数 Vv = 0.41409；
- VSPAERO 正常收敛，报告生成成功；
- 117 项自动化测试通过。

后视验证图：`validation/twin_tail_e2e/fig_twin_tail_rear.png`。

## 4 注意

- 双垂尾当前安装在平尾两端，属于概念设计几何；
- 总垂尾容量保持目标值，但两片垂尾的干涉、颤振、结构载荷和舵面冗余尚未分析；
- 若提示词同时要求“飞翼 + 双垂尾”，飞翼布局没有独立尾翼，仍会按飞翼处理，并应在后续增加冲突假设提示；
- 该修复不改变“概念分析不是已验证可行”的可靠性状态。

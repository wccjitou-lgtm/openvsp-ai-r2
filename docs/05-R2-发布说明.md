# OpenVSP 3.51.3-zh-CN R2 发布说明

- **版本**：R2（`3.51.3-zh-CN-r2`）
- **日期**：2026-11-01
- **基座**：OpenVSP 3.51.3 汉化版 R1（源码树 + R1 安装载荷）
- **产物**：`OpenVSP-3.51.3-zh-CN-r2-Portable.zip`（便携版目录 + 源码补丁 + 文档）

## 1. 新增功能

### 1.1 AI 设计模块（GUI 内置）

- 主菜单栏新增 **AI辅助 → AI 设计...**；
- 服务商：DeepSeek / GLM（智谱）/ Kimi（月之暗面）/ GPT（OpenAI）/ 自定义；
- 请求地址、API Key（密码框、DPAPI 加密保存）、模型列表拉取（WinHTTP）；
- 自然语言设计需求输入；
- **上传技术文档**：Word（.docx）、PDF、Excel（.xlsx/.xls）、TXT/MD/CSV/JSON；后端解析文档中的技术参数、设计输入、设备选型与约束，与自然语言需求合并后参与设计；
- **机身规则（五截面圆筒）**：机身固定 10 个等半径圆截面、均匀分布，首尾圆形端盖；长度按 0.82~0.84 翼展经验并满足尾臂/重心/焦点；飞翼默认可无独立机身；AI 可调用 `openvsp_list_fuselage_styles`。
- **经验设计准则与多轮迭代**：内置机翼/尾翼容量/静稳定性/飞行品质/操纵性准则；分析后自动评估并按失速、尾容量、上反角修正，最多复算 2 轮；报告输出准则表与迭代表。
- **翼根/平尾根裁剪**：按机身局部宽度外移机翼/平尾根部 Y，缩短并重算暴露根弦/面积；VSPAERO 使用暴露气动面，报告同时给出完整几何面积与暴露面积。
- **Profili 翼型库与 AI 自动选型**：本机 Profili 库导入 2200+ 翼型；按任务/Re/Ma 自动选择，真实坐标导入 OpenVSP 参与 VSPAERO；新增 `openvsp_list_airfoils` 工具。
- **MCP调用**：AI 面板底部新增“MCP调用”按钮，弹出五类 Agent（Codex/Claude Code/Kimi/ZCode/DSH）安装教程；`mcp/install_mcp.py` 自动配置并验证，Agent 可直接调用 OpenVSP；
- **上传案例（.vsp3）**：读取案例主翼/机身/尾翼等参数作为基线，AI 按自然语言需求修改/优化，GA 也优先以案例为基线；
- **请求地址按服务商预设/切换**：DeepSeek/GLM/Kimi（Kimi Code 与月之暗面双地址）/OpenAI 各有默认地址，最后一项自定义；切换服务商自动切换地址、模型与 Key；
- **API Key 保存与多服务商记忆**：Key 输入框右侧“保存”按钮，按服务商分别 DPAPI 加密保存；切换服务商自动载入并实际调用模型验证；启动时自动恢复并验证，配置文件中无明文 Key；
- **遗传算法优化**：按当前工况对翼面积/展弦比/梢根比/后掠/上反/尾翼面积做 GA + VSPAERO 实际评估，输出优化 vsp3 与 GA 报告；
- **导入OpenVSP**：把最近一次 AI 设计/GA 优化生成的 vsp3 导入当前 OpenVSP 主窗口直接编辑；
- 一键完成：需求/文档解析 → OpenVSP 建模 → VSPAERO 计算 → 自动优化 → Word 设计报告；
- 运行日志实时显示，支持停止/打开报告；
- 无 Key 时自动使用离线规则设计模式。

### 1.2 AI 设计后端（`ai/`）

- OpenAI 兼容 provider 适配（含模型列表、工具调用、错误归一化）；
- tool-calling 循环 + 内置确定性设计器（离线兜底）；
- OpenVSP/VSPAERO 桥接（几何、极曲线、稳定性、侧滑、导出）；
- 按内置模板生成中文 Word 设计报告；
- 测试与使用说明。

### 1.3 MCP 服务器（`mcp/`）

- stdio + 换行分隔 JSON-RPC 2.0；
- legacy 握手（`protocolVersion=2025-11-25`），兼容 Claude Desktop / Cursor / DSH；
- 工具：状态、建模、几何查询、VSPAERO、导出、报告、文件列表；
- 独立安装/配置说明与 stdio 自测脚本。

### 1.4 工程与发布

- R2 源码补丁（`patches/source-changes/` + `patches/r2-ui.patch`）；
- R2 文档（架构、使用、开发、调研、发布）；
- 便携打包脚本 `scripts/package_r2.py` 与 SHA-256 校验。

## 4. 已知问题

1. 便携版**未内嵌 Python 运行时**：AI 后端需要本机 Python 3.10+（提供 `setup_ai_env.bat`）；后续可加嵌入式 Python。
2. 复杂“厚体机身 + 薄面机翼 + 操纵面切口”的 VSPAERO 混合模型可能数值不稳定；后端内置**全薄面 VLM 降级**，并会在日志/报告中注明。
3. 智谱 `/models` 接口官方未文档化，模型列表可能回退内置清单；请以控制台模型 ID 为准。
4. MCP 目前仅支持 legacy 握手；modern（2026-07-28）客户端需要后续 dual-era 适配。
5. 长任务“停止”会终止 Python 进程，可能残留 VSPAERO 子进程；后续增加进程树清理。
6. R2 未做代码签名/安装器（便携版）；R1 的 NSIS 打包管线可在后续版本复用。

## 5. 五案例设计验证

R2 已完成五个不同构型案例的设计、VSPERO 计算与工程校核，详见：
[06-五案例设计验证报告](06-五案例设计验证报告.md)（Word/PDF 同目录）。

- 案例：C1 常规布局电动长航时、C2 飞翼侦察、C3 V 尾涡喷高速靶机、C4 大展弦比高空长航时、C5 串列翼参考算例；
- 计算：全部生成可编辑 vsp3 并通过 VSPAERO（全薄面 VLM）极曲线/稳定性计算；
- 符合性：C4/C5 满足需求；C1（翼展与 AR 几何冲突）、C2（飞翼静稳定裕度 28.1% 未达 10%）、C3（后掠角未生效、高速 L/D 偏乐观）部分满足并给出改进建议；
- 常规经验：CLα 4.33~5.95 /rad、CD0 0.007~0.010、L/Dmax 与经验式比值 0.98~1.18，量级合理；
- 大模型验证：C1~C4 均为 `mode=llm`、DeepSeek `deepseek-flash`、4 轮工具调用；离线对照为 `mode=offline` 无工具调用，证明大模型 API 真实参与设计。

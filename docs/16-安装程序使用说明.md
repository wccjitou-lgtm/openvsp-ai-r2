# OpenVSP AI R2 安装程序说明

**安装包：** `dist/installer/OpenVSP-AI-R2-Setup-3.51.3-r2.exe`  
**大小：** 62.6 MB  
**SHA-256：** `117C83084332ED9BD480601A25F6FE8CA93882A839FFCCABCD35637A912D8876`  
**默认安装目录：** `%LOCALAPPDATA%\Programs\OpenVSP AI R2`

## 安装内容

- 完整便携版 OpenVSP AI R2 文件（不含用户输出和 Profili 数据库）；
- 开始菜单快捷方式；
- 可选桌面快捷方式；
- 卸载程序。

## 安装后自动同步

安装器在 `ssPostInstall` 阶段写入：

1. **用户环境变量**
   - `OPENVSP_R2_ROOT`
   - `OPENVSP_ROOT`
   - `OPENVSP_PYTHONPATH`
   - `OPENVSP_MCP_SERVER`
   - `OPENVSP_MCP_INSTALLER`
   - `OPENVSP_R2_VERSION`

2. **安装上下文文件**
   - `mcp\install_context.ini`
   - 包含 `APP_ROOT`、`PYTHON`、`OPENVSP_ROOT`、`OPENVSP_PYTHONPATH`、`MCP_SERVER`、`MCP_INSTALLER`。

3. **MCP 提示词同步**
   - 点击 GUI 中的 **MCP调用** 时，程序读取 `install_context.ini`；
   - 提示词顶部会显示本机安装路径；
   - 如果提示词被复制到另一台电脑，程序仍保留“重新定位 APP_ROOT”的通用步骤。

## 静默安装

```powershell
.\OpenVSP-AI-R2-Setup-3.51.3-r2.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\OpenVSP AI R2"
```

注意：`/DIR` 整个参数需要带引号，否则包含空格的路径可能被拆开。

## 验证

- 安装后检查 `{安装目录}\mcp\install_context.ini`；
- 检查用户环境变量 `OPENVSP_R2_ROOT`；
- 启动 OpenVSP，点击 **MCP调用**，确认提示词顶部出现本机安装路径。

## 卸载

从“应用和功能”运行卸载程序，或运行 `{安装目录}\unins000.exe`。

卸载时会移除本次安装写入且仍等于安装目录的环境变量；不会删除用户自己的其他 OpenVSP 配置。

## 注意

- 安装包未做商业代码签名，Windows SmartScreen 可能提示未知发布者；请核对 SHA-256。
- 安装器不自动执行 MCP 安装；它将路径同步给 Agent，由 Agent 根据提示词完成 MCP 注册。
- 如果目标电脑没有 Python，提示词会要求先安装 Python 3.11+。

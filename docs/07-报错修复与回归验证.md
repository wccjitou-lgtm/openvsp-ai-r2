# OpenVSP R2 五案例报错修复与回归验证

> 日期：2026-11-01  |  范围：五案例验证中暴露的后端缺陷  |  结论：4 类真实缺陷已修复并通过回归测试（91 passed）。

## 1. 审计结论

五个案例的最终运行日志中，除“未识别速度范围”“达到 max_iterations”等**非致命警告**外，未再出现 `[error]`；但验证过程与结果字段暴露出 4 个真实缺陷，均已修复：

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 飞翼案例 VSPAERO 报“polar 升力系数无效”（早期 C2 两次运行） | `size_aircraft` 的 flying_wing 分支提前 return，`sizing` 中缺少 `area_m2/span_m/mac_m`，导致 VSPAERO `Sref=0` | 在初始 `sizing` 字典中补充 `area_m2/span_m/mac_m`；C2 极曲线恢复正常（CLmax 1.82、L/Dmax 26.3） |
| 2 | C3 大模型调用 `openvsp_modify_parameter` 设置后掠 15° 返回 ok，但最终模型仍为 0° | `modify_parameter()` 修改 geometry 后调用 `build_aircraft()`，后者重新 `size_aircraft()` 用 spec 覆盖了修改值 | 修改后直接用修改版 geometry 调 `bridge.build_geometry()` 重建、保存、重算；验证后掠 15° 保留且 vsp3 回读 15° |
| 3 | C2 飞翼静稳定裕度 28.1%，未达 10% 目标 | 重心目标限位使用“翼弦 60%”上限，飞翼重心目标被截断 | 飞翼构型放宽到 95% 翼弦，并在限位生效时输出 warning；验证 SM=10.0% |
| 4 | C1 `result.json` 中 design.aspect_ratio 显示 9，但实际几何 AR=5.98 | metrics 的 design 字段直接取 spec，未反映实际几何；需求冲突无提示 | design 中增加 `actual_wing_area_m2/actual_span_m/actual_aspect_ratio`，AR 偏差 >5% 时输出 warning |
| 5 | 日志出现 `Error Code: 5 ... VSPAERO_THIN` | OpenVSP API 初次查找薄面集时的已知无害打印 | UI 已过滤并显示一次说明；不影响计算 |
| 6 | 日志出现 `Zero direction vector in MakeArrowhead!` | OpenVSP 退化几何/导出阶段的非致命打印 | 不影响 vsp3/polar/结果；建议后续在后端 stdout 过滤 |
| 7 | 警告“未识别速度范围，按 25~45 m/s 估算”“达到 max_iterations” | 自然语言未给出完整速度范围；LLM 达到 4 轮上限 | 属假设/迭代提示，不是报错；可在提示词中补充速度范围或提高 max_iterations |

## 2. 修复验证

- **C3 后掠角持久化**：修改 `wing.sweep_deg=15` 后，`designer.geometry["wing"]["sweep_deg"] == 15.0`；`read_model_parameters(model_path)` 回读 `sweep_deg=15.0`。
- **C2 飞翼静稳定裕度**：修复后离线复算 `static_margin=0.100`、`xcg=0.7011 m`、实际 AR=7.0。
- **C1 指标一致性**：新增 `actual_aspect_ratio/actual_span_m/actual_wing_area_m2`；当实际 AR 与需求偏差 >5% 时日志输出“需求展弦比与实际几何不一致，请检查需求冲突”。
- **回归测试**：新增 `tests/test_designer_regressions.py`（2 项真实 OpenVSP/VSPAERO 回归）；全量 pytest：**91 passed in 45.44s**。

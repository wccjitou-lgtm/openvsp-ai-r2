# 自然语言迭代修改当前设计

**日期：** 2026-11-02  
**状态：** 已接入 AI 设计面板  
**适用：** 已安装 AI 后端并具备可用 LLM（无 Key 时可走离线规则回退）

## 1 使用方式

1. 在 AI 设计面板输入第一轮需求，点击 **开始设计**；
2. 第一轮完成后，**修改当前设计** 按钮变为可用；
3. 在同一个需求文本框中填写修改要求，例如：
   - `把翼展改为 3.5 m，保持其他参数不变，重新校核静稳定`
   - `垂尾改成双垂尾，平尾不动`
   - `巡航速度改为 30 m/s，重新计算 L/D 和失速速度`
4. 点击 **修改当前设计**。

系统会：

- 以最近一次生成的 `design_model.vsp3` 作为当前基线；
- 把当前模型、参数、上一轮 result.json 注入 LLM 上下文；
- 让 LLM 通过 OpenVSP 工具修改参数或重建模型；
- 重新运行 VSPAERO、静稳定/准则检查和报告生成；
- 输出到新的时间戳目录，保留上一轮结果。

## 2 后端配置

GUI 生成的 `ai_job.json` 包含：

```json
{
  "task": "modify",
  "modify": true,
  "prompt": "把翼展改为 3.5 m",
  "case_model": "<上一轮 design_model.vsp3>",
  "parent_model": "<上一轮 design_model.vsp3>",
  "parent_result": "<上一轮 result.json>"
}
```

`AIConfig` 将 `task=modify` 原样传递；`DesignAgent` 会在 LLM user 消息中加入“当前设计修改任务”块，要求：

- 只修改用户点名内容；
- 其他参数沿用上一轮；
- 修改后重新运行 VSPAERO、稳定性和报告；
- 不把旧结果冒充新结果。

无可用 LLM 时，离线规则流程会用当前 `.vsp3` 作为案例基线，按自然语言解析出的参数修改后复算。

## 3 验证

已用当前模型作为基线测试：

```text
task=modify
case_model=<上一轮模型>
parent_model=<上一轮模型>
parent_result=<上一轮结果>
prompt=把翼展改为 3.0 m...
```

结果：

- 新模型翼展 = 3.00 m；
- 新 `result.json` 的 `task=modify`、`modify=true`；
- 父模型/父结果路径保留；
- 重新生成 VSPAERO 结果和 Word 报告。

## 4 限制

- 这是概念设计层的参数/几何迭代，不是通用 CAD 装配编辑；
- LLM 修改能力仍受工具 schema 限制；
- 用户要求与已有参数冲突时，以显式修改为准，但会在 assumptions/日志中提示冲突；
- 可靠性状态仍是 `analysis_only` 级别，不等于已验证或飞行放行。

# Validation evidence

This directory contains lightweight, public-safe evidence used to demonstrate
the current prototype: four-layout result summaries, screenshots, and the M0/M1
reliability records. It is **not** an acceptance record and does not contain the
private audit logs, API credentials, generated solver runs, or Profili data.

The 62 acceptance cases in `docs/reliable_design_v1/` remain `NOT_RUN` until
executed and signed independently.
